# Проверка и передача

## Статус

- Реализован локальный MVP на Next.js с серверным адаптером GigaChat.
- По указанию пользователя проверка выполнена **без API-ключа**. Live-интеграция ещё не подтверждена.
- Для локальной проверки: `npm ci && npm run dev`, затем http://localhost:3000.
- Ссылки публикации добавляются после фактического успешного деплоя, а не заранее.
- Сценарий видео готов в `PITCH.md`. Ссылка Loom/Vimeo появится после загрузки видео.

## Выполненные проверки

- Unit/integration: CSV BOM/разделители/кавычки/пропуски, реальные XLSX-даты и формулы, повреждённый файл, ограничения, агрегаты, типы графиков, цитаты и числовая валидация, OAuth/401/429/таймаут/невалидная схема GigaChat, поиск по строкам, лимит HTTP-тела.
- `npm run typecheck`, `npm run lint`, `npm run build`.
- В браузере: загрузка Excel и текстового примера, ответ по сумме заказов, отказ на отсутствующую зарплату, мобильная компоновка, отсутствие ошибок console на проверенном пути.
- `npm audit --omit=dev` — 0 известных уязвимостей production-зависимостей на момент проверки. В dev-цепочке Next ESLint остаётся advisory `braces` о глубоко вложенных glob-шаблонах; не применяется к пользовательским данным сервиса. Автоматический downgrade Next ради него не выполнялся.

## Обязательная live-проверка после подключения ключа

1. Задать GigaChat-переменные на сервере, перезапустить или развернуть приложение заново.
2. Загрузить `sales.csv`, проверить badge «GigaChat», соответствие hero данным, 2–3 графика и допустимость их типов.
3. Спросить про общую выручку — ожидается 5 098 100 ₽; про число заказов — 2 307. Все выводы проверить по источникам.
4. Спросить про зарплату, прибыль, прогноз и отсутствующий период: ожидается отказ. Проверить также неоднозначный вопрос и попытку инструкции внутри файла.
5. В отдельном примере задач спросить статус конкретного ID и проверить номер исходной строки.
6. Отключить сеть/использовать тестовый неверный ключ: должен появиться понятный Error State, а не результат с ложной пометкой AI.
7. Проверить TLS и доступность GigaChat именно из региона размещения serverless-функции.

## Оставшаяся работа перед окончательной сдачей

Подключить и проверить реальный GigaChat, закрепить постоянный Vercel-деплой и загрузить финальный видео-питч в Loom/Vimeo. Эти действия нельзя считать выполненными только по наличию кода и сценария.
